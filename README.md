**Sistema de Gestion de Inventario con Colecciones en Python**

**Descripcion:**
Programa de consola desarrollado para resolver la gestion y control de inventario de una tienda de componentes y articulos mediante el uso de colecciones de datos.

**Estructura de datos empleada:**
Se utilizo un diccionario principal donde cada clave representa un codigo unico de producto, asociado a su descripcion, precio unitario y cantidad en stock.

**Funcionalidades incluidas:**
- Mostrar inventario completo en formato de tabla.
- Registrar nuevos productos validando datos numericos.
- Buscar productos especificos mediante su codigo unico.
- Eliminar productos existentes del registro.

**Instrucciones de ejecucion:**
1. Abrir una terminal en el directorio del proyecto.
2. Ejecutar el comando: python inventario_tienda.py
